# Ideas

This folder is for rough gameplay, physics, UI, scenario, and tuning ideas.

Rough notes live in `ideas/rough/` so early concepts stay grouped together.

Resolved notes live in `ideas/resolved/` so completed investigations remain searchable without looking active.

Suggested format for new notes:

```md
# Idea title

## Context
What problem or opportunity this idea is about.

## Proposal
What could be added or changed.

## Open questions
What still needs testing or design decisions.

## Status
Rough / promising / tested / rejected / implemented
```

Keep notes lightweight. It is fine for ideas here to be incomplete.
