## Context
The main mobile control scheme is implemented and already usable, but touch UX usually needs another pass once people start playing on real devices. There is still room to improve gesture clarity, responsiveness, and edge-case behavior without redesigning the system from scratch.

## Proposal
Do a focused polish pass on mobile interactions. Likely areas include gesture tolerance, accidental input prevention, menu touch behavior, haptic consistency, device-specific Safari/Android quirks, and overall comfort during longer play sessions.
