# Trajectory tools

## Context
Trajectory prediction is central to the game, but it still asks a lot from the player. More support around prediction controls and maneuver planning could make the game deeper without making it less simulation-driven.

## Proposal
Expand the trajectory toolset with better prediction controls, clearer maneuver previews, and stronger hints about how steering or burns will affect the current path. The goal is to improve planning depth while preserving the satisfaction of flying manually.

## Open questions
- Which additions are most valuable first: horizon controls, clearer target relations, or maneuver preview aids?
- How much should the game explain versus leaving as an expert tool for players to learn?
- Can new trajectory tools stay readable on mobile without crowding the screen?
