# Progression layer

## Context
The core flight interactions can be satisfying moment to moment, but the game currently has little long-term structure. Even a lightweight progression layer could make repeated play feel more purposeful.

## Proposal
Add a simple progression system such as medals, stars, unlocks, score thresholds, or challenge completion markers. The system should reward mastery without turning the game into a grind.

## Open questions
- What is the smallest progression layer that adds motivation without distorting the core experience?
- Should unlocks gate missions, tools, or only cosmetic achievement markers?
- How should progression interact with the tutorial and any future free-play mode?
