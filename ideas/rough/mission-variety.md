# Mission variety

## Context
The current core mechanics are starting to hold together, but the game still needs more reasons to use them. A wider set of mission goals would make the sandbox feel more like a game and expose different parts of the flight model.

## Proposal
Add a small set of distinct scenarios such as rendezvous, fuel-efficient transfer, time-limited approach, or return-to-Earth challenges. Each mission should emphasize a different skill and create a clearer sense of progression than repeating one open-ended task.

## Open questions
- Which 2 or 3 mission types best fit the current mechanics without needing major new systems?
- Should missions share one persistent world state or remain separate scenario entries?
- How should success be measured: completion only, or graded performance such as time and fuel use?
